# 六张肖像 · 生图清单

最后更新：2026-11-21
用途：给用户直接用生图 AI 产出 s3–s8 的场景肖像，然后由 AI 接入代码。
本文件只在本地保留，**不要随站点发布**。

---

## 0. 先看这一条

**你要产出的不是照片，是「铅笔素描插画」。**

整站是纯白底 + 纯黑线描（SVG 线稿，无填充、无彩色）。如果肖像是有明暗摄影质感的照片，
拼进页面会立刻出戏。现有的 `portrait-1.jpg`、`portrait-2.jpg` 就是铅笔素描风，必须延续。

三条不可动摇：

1. **铅笔素描质感**，不是摄影、不是厚涂、不是水彩。
2. **同一位女生**（和现有两张一致），否则八景会变成八个人。
3. **纯白背景 + 画面里只有人**。不要画站台、海、房间、街、伞、城市、灯光——
   这些在页面里已经由 SVG 线稿负责，肖像再画一遍会重叠穿帮。

## 1. 尺寸与构图（重要，和你原来的设想可能不同）

页面里的肖像由这段 CSS 控制（`styles.css` `.scene-portrait`）：

```css
object-fit: cover;      /* 按比例放大后裁切 */
position/width/height:  约 38% 宽 × 77% 高（一个偏瘦的竖框，宽高比约 0.6）
mask-image:            径向椭圆羽化，边缘淡出到纯白
filter:                grayscale(1) + 轻微 brightness/contrast + blur(.15px)
opacity:               .9
```

竖框的宽高比会随视口变化（约 0.47–0.63），下表按桌面约 0.59 估算。
`object-fit: cover` 会把横图的左右大量裁掉：

| 图片宽高比 | 实际能看到的画面宽度（估算） |
|---|---|
| 2.09:1（现在的两张） | **仅约 29%** |
| 3:2 | 约 40% |
| 1:1 | 约 60% |
| **4:5（推荐）** | **约 75%** |
| 3:4 | 约 80% |

也就是说现有两张长条图有七成像素是被裁掉的，只是恰好人物居中才没露馅。

**所以请按 4:5 竖图生成**，能利用的像素最多、脸也最清楚：

- 比例 **4:5**，建议 `1024×1280` 或 `1200×1500`（长边 ≥1200 更好）
- 人物**水平居中**，占画面宽度 55–70%
- 头顶留白 **8–15%**
- 底部裁到**胸口或腰线**，让人物自然淡出，不要出现完整全身
- 四周**纯白 #FFFFFF**，不要渐变、不要纸纹、不要投影、不要暗角

> 只能出 1:1 或 3:4 也完全可用，我会自己裁。构图对了就行，比例不理想不是问题。

## 2. 身份一致性（唯一真正难的地方）

六张必须和现有两张是同一个人。两个办法，任选：

**A. 用参考图（推荐）**
把 `assets/portrait-2.jpg` 当参考图/角色图喂给生图工具——它是正面、五官最清楚的一张。
支持参考图的工具：即梦/Seedream 4.0（参考图）、Nano Banana / Gemini 图像（多图参考）、
Midjourney（`--cref <url> --cw 100`）、GPT-image-1（图片编辑）、Flux Kontext。

**B. 锁定文字描述**
每张都重复同一段人物描述（见第 4 节「人物块」），只用同一套种子/风格词。

如果六张的脸漂移明显，**更省事的做法是八张一起重生成**（含 s1、s2），全部用同一个身份参考。
我这边换图成本很低，只要 `src` 指向新文件即可，不改任何逻辑。

人物锚点（写提示词时别丢）：

- 亚洲年轻女性，22 岁左右，鹅蛋脸，五官清秀，鼻梁细直，双眼皮
- 黑色长发，自然微卷，发量多，中分/偏分
- **圆形细金属框眼镜** —— 两张现有图都有，是识别度最高的锚点，务必保留
- 神情安静、克制、略带疏离（不是大笑、不是浓妆）

## 3. 六张分镜

按文档建议的优先顺序：**深夜书桌、车站、天台** 先出，其余随后。

| # | 场景 | 一句话 | 服装 | 关键动作 |
|---|---|---|---|---|
| s3 | 地铁站 · 末班车之前 | 站台的风从隧道深处涌上来 | 深色大衣 + 浅色围巾 | 侧身回望，**单边耳机** |
| s4 | 海边 · 退潮以后 | 赤脚走过湿沙 | 浅色长裙/薄外套 | **手提鞋**，回眸，头发被风吹乱 |
| s5 | 房间 · 台灯亮到很晚 | 灯还亮着，人已经困了 | 针织开衫 | 托腮/抱膝，**带倦意** |
| s6 | 雨街 · 岔路口的红灯 | 红灯前，雨落在伞面上 | 立领风衣 | **侧影**，安静望向远处 |
| s7 | 车站 · 站台之外 | 广播响了两遍 | 大衣 + 围巾 | 手扶行李拉杆，**回头** |
| s8 | 天台 · 天台的月亮 | 很久以后，你又路过那座城市 | 长外套 | 侧脸，**平静而疲惫** |

每张的注意点：

- **s3**：耳机线从耳垂垂下来一点即可，不要画站台、列车、灯箱。
- **s4**：手提高跟鞋垂在身侧，赤脚的脚踝可以不出现（裁到腰）；风只吹头发，不画浪、不画沙。
- **s5**：用「一侧脸亮、一侧深」的排线表现台灯，用一点冷调排线表示手机微光；
  但整体仍是石墨灰，**不要出现黄色光晕**。桌、台灯本体都不要画。
- **s6**：伞最容易穿帮。**只允许出现肩上一角伞面或伞柄**，不要完整伞和雨丝。
  湿润感用发梢的深色排线和贴在额前的一缕头发表现。
- **s7**：行李箱同理，**只画手扶拉杆的动作**，不要画箱体；回头要「欲言又止」，不是微笑。
- **s8**：这是全片唯一「多年后」，可以比 s3–s7 略成熟（发型更整齐、眼神更沉），
  但**不能变成另一个人**。栏杆、城市灯光、月亮都不画。

## 4. 提示词

用法：**风格块 + 人物块 + 该张分镜块 + 构图块** 拼起来即可，风格块和人物块六张完全复用。

```

纯白背景（#FFFFFF），画面中只有一个人物，没有背景景物，
没有文字，没有签名，没有水印，没有边框，没有投影，
古典铅笔肖像画风格，安静克制的氛围
```

## 5. 交付

- 文件名：`portrait-s3.jpg` … `portrait-s8.jpg`
- 放进 `D:\Astroswarm\function-farewell-mono\assets\`
- JPG，质量 85 左右，**单张 ≤300KB**（现在两张约 94KB）

## 6. 拿到图之后我做什么

1. 裁到 4:5、压到目标体积，必要时转真灰度。
2. 改 `js/scene-art.js` 里对应场景的 `portrait.src`，并逐张微调 `spot` / `focus` 让脸落在正确位置。
3. 递增 `?v=` 版本号（防浏览器缓存旧图，这是历史上「改了没生效」的根因）。
4. 跑 `node tests/content-test.js` + `node tests/animation-qa.js`，桌面与手机截图逐张看。
5. 按 `HANDOFF.md` 第 6 节备份 → SHA-256 比对 → 部署 → 线上验收。
6. 更新 `HANDOFF.md` / `AI_HANDOFF.md` 的哈希与记录。
