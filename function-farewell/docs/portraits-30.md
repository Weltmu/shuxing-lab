# 《函数式告别》30 幕人物图 · 生成规格与提示词

## 一、统一规格（30 张都按这个来）

| 项 | 要求 |
|---|---|
| 画风 | 黑白铅笔 / 炭笔素描，细腻排线，纸面质感；**不要**彩色、不要厚涂、不要 3D 渲染、不要动漫赛璐璐 |
| 构图 | **半身或胸像**，头顶留少量空白，身体延伸到画面底边（便于桌面遮挡） |
| 朝向 | 人物**看向画面左侧**（页面文字在左边），三分之二侧脸或正面 |
| 背景 | 纯白或浅灰纸底，**不要**边框、不要文字、不要水印、不要其他人物 |
| 比例 | **竖构图 3:4**，建议 900×1200（或 1000×1330，越大越好） |
| 一致角色 | 同一位女性：**黑色中长发、细框圆眼镜、安静气质**；服装随季节变，脸型五官保持一致 |
| 建议做法 | 先确定一张"标准脸"，之后每张用同一 seed 或参考图（image reference）保持角色一致 |
| 文件名 | `portrait-m01.png` … `portrait-m30.png`（放 `assets/` 目录即可） |

> 页面会自动给每张图做"白底抠像 + 边缘羽化"，所以背景越干净，合成越自然。
> 人物会显示在画面**右侧**、约 500×390 的区域，所以人物尽量居中偏右、不要贴边。

## 三、交付方式

1. 按上面 30 条生成，命名为 `portrait-m01.png` … `portrait-m30.png`，放 `assets/` 目录
2. 一起发我（或告诉我路径），我做三件事：
   - 白底抠像 + 边缘羽化（和现在同样的处理）
   - 接到 `js/scene30.js` 的对应幕
   - 逐幕截图核对一遍再交给你
