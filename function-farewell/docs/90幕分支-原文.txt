一、隐藏亲密度计分规则（核心，先读懂再写代码）
分数叫什么：亲密度（后台叫 affinity，只在代码里出现）。玩家永远看不到这个数字，界面上不显示分
数、不显示进度条、不显示“亲密度＋1”之类的提示。玩家只能从她的表情和回响里感觉到关系变了。
起始值：0。每选 1 个选项加多少分：用这个选项已有的 signal 算：亲密度变化＝t＋h＋a，再限制在 −2 
到 +2 之间。t 是温度（−1 退开 / 0 中性 / 1 靠近），h 是坦诚（−1 绕开 / 0 中性 / 1 说实话），a 是主动
（−1 被动 / 0 中性 / 1 主动）。例如一个选项 signal 是 t=1、h=1、a=1，t＋h＋a＝3，限制后加 +2；一
个选项 t=−1、h=−1、a=−1，加 −2；一个选项 t=1、h=0、a=0，加 +1。
上下限：分数限制在 −12 到 +12 之间，加过头了按 12 算，减过头了按 −12 算。分数存在后台一个变量
里，每局新开一局就清零。
